# Plus Infinity

PWA simples, em português, com atalhos para os serviços oficiais ChatGPT e Claude. Inclui tema claro/escuro, cor de destaque e cache básico offline.

## Publicar sem créditos do Lovable

Este projeto é estático e não precisa de backend, banco de dados, chave de API ou conta paga no Lovable.

1. Abra **Settings** deste repositório no GitHub.
2. Entre em **Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/(root)`, depois salve.
5. Aguarde a URL ser apresentada na página Pages.

Se a opção de branch não estiver disponível, use a fonte **GitHub Actions** e configure um workflow de Pages.

## Adicionar ao iPhone

1. Abra a URL publicada no Safari.
2. Toque em **Compartilhar**.
3. Escolha **Adicionar à Tela de Início**.
4. Confirme em **Adicionar**.

## Privacidade

Não há login, analytics, backend nem coleta de dados. As preferências de aparência ficam no armazenamento local do navegador. Os botões abrem os sites oficiais em novas abas.
